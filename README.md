# campus-mind-website

Source of record for the coded sections of [campusmind.org](https://www.campusmind.org), which runs on Grigora.

Each page is a stack of sections. Each section is one **Custom HTML** block in Grigora's editor. Claude writes and updates the code here; Burke pastes the blocks into Grigora and publishes.

## How to use it

1. Open `dist/<page>/<section>.html` on GitHub and copy the whole file.
2. In Grigora, paste it into that section's **Custom HTML** block (Edit HTML). Don't use the **Code** element; it shows code as text.
3. Preview at desktop and phone sizes, then publish.

## How it's built

- `styles/cm-web.css`: the shared Campus Mind styles (brand colors, type, buttons, cards, phone layouts). Every rule is scoped to `.cmw`, so nothing else on the site is affected.
- `sections/<page>/`: section markup only.
- `dist/<page>/`: paste-ready blocks (styles + section). Generated by `python3 build.py`; don't edit by hand.
- `*.standalone.html`: blocks that carry their own styles (blog archive, student check-in iframe), copied as-is.
- `drafts/`: sections waiting on something (e.g. a video upload).

Why each block carries its own styles: Grigora's Custom HTML block doesn't pick up site-wide head code, so styles must travel inside the block. Live blocks may carry older style versions; they keep working, since each has its own copy. Planned upgrade: host `cm-web.css` on campusmind.io and load it with one `<link>` line per block.

### Rules learned in Grigora

- Put each block in a full-width Section with 0 padding and no frame.
- Grigora overrides margins on `<p>` elements (v1.12 forces paragraph spacing inside `.wrap`). Use `<div>` (or `!important`) for anything that needs outer spacing or centering.
- Links that leave the page use `target="_top"`.
- Custom HTML blocks render straight into the page (no frame; checked live Nov 27), so an ID inside the block is enough for jump links. Grigora builds the page after the browser tries the jump, so arriving from another page needs a small jump-on-load script (see `sections/facultydevelopment/01-demo.html`).
- Files (PDFs) live in Grigora Files, root-files/. GA4 counts `.pdf` link clicks as `file_download`; PDF links also carry a small onclick that sends the event to the parent page when the block runs in a frame (no double count otherwise).
- Icons are inline SVG, outlined at a 2px stroke, drawn for Campus Mind.
- Iframes only for the app (the check-in at campusmind.io). Words go in coded sections so Google indexes them.
- Header and footer stay native Grigora.
